## Directory Purposes

**`gateway/`:**
- Purpose: API Gateway + React SPA frontend
- Contains: Spring Boot gateway server, React TypeScript SPA, reverse proxy config, Feign clients (to call microservices)
- Key files: `GatewayApp.java`, `src/main/webapp/` (React components)

**`portfolioService/`:**
- Purpose: Core portfolio domain logic (Phase 1 — complete)
- Contains: 10 JPA entities, REST API (GET/POST/PUT/DELETE for each), QueryService for filtering, Liquibase migrations
- Key files: `PortfolioServiceApp.java`, domain/*.java (10 entities), service/impl/, web/rest/*Resource.java

**`tradingService/`:**
- Purpose: Order execution, trade fills, slippage tracking (Phase 4 — stub only)
- Contains: Skeleton structure (no entities yet)
- Key files: `TradingServiceApp.java`, broker/KafkaConsumer.java (listens for portfolio updates)

**`notificationService/`:**
- Purpose: Alert rules, email/webhook notifications (Phase 2 — stub only)
- Contains: Skeleton structure (no entities yet)
- Key files: `NotificationServiceApp.java`, broker/KafkaConsumer.java (listens for portfolio updates, triggers alerts)

**`kubernetes/`:**
- Purpose: Infrastructure-as-Code for deployment to Kubernetes cluster
- Contains: YAML manifests for each service (Deployment, Service, ConfigMap, Ingress), PostgreSQL StatefulSets, Kafka broker config
- Key files: `*/deployment.yaml` (container image, replicas, resources), `*/service.yaml` (expose port), `gateway-k8s/ingress.yaml` (public entry point)

**`.planning/codebase/`:**
- Purpose: GSD codebase analysis and reference documents
- Contains: ARCHITECTURE.md, STRUCTURE.md, and optional STACK.md, TESTING.md, CONCERNS.md
- Key files: Analysis snapshots for `/gsd-plan-phase` and `/gsd-execute-phase` to reference

**`.claude/`:**
- Purpose: Claude Code agent configuration for GSD workflow
- Contains: Skills, hooks, scripts, settings
- Key files: `settings.json` (permissions), `gsd-core/` (GSD framework), `hooks/` (git pre-commit)

**`.github/workflows/`:**
- Purpose: GitHub Actions CI/CD pipelines
- Contains: Build, test, Docker push workflows for each service
- Key files: `portfolio-service-ci.yml` (build matrix, maven goals, docker steps)

## Naming Conventions

**Files:**
- Entity: `Asset.java`, `Operation.java`, `Position.java` (singular, PascalCase, @Entity annotation)
- Repository: `AssetRepository.java`, `OperationRepository.java` (PascalCase, extends JpaRepository)
- Service: `AssetService.java`, `AssetQueryService.java` (PascalCase, interface or @Service)
- DTO: `AssetDTO.java`, `OperationDTO.java` (PascalCase + DTO suffix)
- Mapper: `AssetMapper.java`, `OperationMapper.java` (PascalCase + Mapper suffix, @Mapper annotation)
- Criteria: `AssetCriteria.java`, `OperationCriteria.java` (PascalCase + Criteria suffix)
- REST Controller: `AssetResource.java`, `OperationResource.java` (PascalCase + Resource suffix, @RestController)
- Config: `DatabaseConfiguration.java`, `CacheConfiguration.java` (PascalCase + Configuration, @Configuration)
- Aspect: `LoggingAspect.java` (PascalCase + Aspect, @Aspect)
- Kafka: `KafkaConsumer.java` (PascalCase + Kafka* prefix/suffix)

**Directories:**
- `domain/` → JPA entities
- `repository/` → Spring Data repositories
- `service/` → Service interfaces + implementations
- `service/dto/` → Data Transfer Objects
- `service/mapper/` → MapStruct mappers
- `service/criteria/` → Query criteria classes
- `service/impl/` → Service implementations
- `web/rest/` → REST controllers
- `web/rest/errors/` → Error utilities (ErrorVM, BadRequestAlertException)
- `config/` → Spring @Configuration classes
- `security/` → Spring Security config, OAuth2 handlers
- `security/oauth2/` → OAuth2-specific config (if needed)
- `aop/logging/` → AOP aspects
- `broker/` → Message broker consumers (Kafka)

**Java Package Names:**
- `com.assetcompass.gateway` (gateway app)
- `com.assetcompass.portfolio` (portfolio service)
- `com.assetcompass.trading` (trading service)
- `com.assetcompass.notification` (notification service)

**REST Endpoint Paths:**
- `/api/assets` (collection of assets)
- `/api/assets/{id}` (single asset by UUID)
- `/api/operations` (collection of operations)
- `/api/operations/{id}` (single operation)
- Similar for positions, valuations, tax-events, income-events, rebates, asset-ratios, brokers, broker-accounts

**Liquibase Changeset Naming:**
- `YYYYMMDD_initial_schema.xml` or `YYYYMMDD_add_table_asset.xml` (timestamp + semantic name)

## Where to Add New Code

**New Feature (Entity + Full CRUD):**
1. Define entity in JDL (`asset-compass.jdl`), then regenerate via JHipster:
   ```bash
   jhipster jdl asset-compass.jdl
   ```
   OR manually:
2. **Domain entity:** `portfolioService/src/main/java/com/assetcompass/portfolio/domain/NewEntity.java`
   - Extend `AbstractAuditingEntity` for audit fields
   - Add @Entity, @Table, @Id (UUID), @ManyToOne/@OneToMany relationships
3. **Repository:** `portfolioService/src/main/java/com/assetcompass/portfolio/repository/NewEntityRepository.java`
   - `public interface NewEntityRepository extends JpaRepository<NewEntity, UUID> { }`
4. **DTO:** `portfolioService/src/main/java/com/assetcompass/portfolio/service/dto/NewEntityDTO.java`
   - Mirror entity fields, add nested DTOs for relationships
5. **Mapper:** `portfolioService/src/main/java/com/assetcompass/portfolio/service/mapper/NewEntityMapper.java`
   - `@Mapper(componentModel = "spring")` interface, auto-generate implementation
6. **Criteria:** `portfolioService/src/main/java/com/assetcompass/portfolio/service/criteria/NewEntityCriteria.java`
   - Setter fields for each filterable column (copied from entity)
7. **Service:** `portfolioService/src/main/java/com/assetcompass/portfolio/service/NewEntityService.java`
   - `public interface NewEntityService { ... }` (CRUD methods)
   - `impl/NewEntityServiceImpl.java` (implementation, @Transactional, calls repository)
8. **QueryService:** `portfolioService/src/main/java/com/assetcompass/portfolio/service/NewEntityQueryService.java`
   - Accepts Criteria, builds Specification, calls repository.findAll(spec, pageable)
9. **REST Controller:** `portfolioService/src/main/java/com/assetcompass/portfolio/web/rest/NewEntityResource.java`
   - @RestController @RequestMapping("/api/new-entities")
   - @GetMapping, @PostMapping, @PutMapping, @DeleteMapping (inject Service + QueryService)
10. **Database migration:** `portfolioService/src/main/resources/config/liquibase/changelog/YYYYMMDD_create_new_entity_table.xml`
    - Liquibase XML changeset (create table, add constraints, add indexes)
11. **Test:** `portfolioService/src/test/java/com/assetcompass/portfolio/web/rest/NewEntityResourceIT.java`
    - IntegrationTest or @WebMvcTest, mock service, test endpoints

**New Component/Module (No Entity):**
- Utility service: `portfolioService/src/main/java/com/assetcompass/portfolio/service/UtilityService.java`
- Kafka producer: `portfolioService/src/main/java/com/assetcompass/portfolio/broker/KafkaProducer.java`
- Custom configuration: `portfolioService/src/main/java/com/assetcompass/portfolio/config/CustomConfiguration.java`
- AOP aspect: `portfolioService/src/main/java/com/assetcompass/portfolio/aop/CustomAspect.java`

**Utilities/Helpers:**
- Shared helpers: `portfolioService/src/main/java/com/assetcompass/portfolio/util/` (if needed, not yet present)
- Math/calc helpers: Keep close to domain (e.g., Position.java for position calculations)

**Testing:**
- Unit tests: `portfolioService/src/test/java/com/assetcompass/portfolio/service/NewEntityServiceTest.java`
- Integration tests: `portfolioService/src/test/java/com/assetcompass/portfolio/web/rest/NewEntityResourceIT.java`
- Test fixtures: `portfolioService/src/test/java/.../web/rest/NewEntityResourceTestSamples.java` (sample data builders)

- Feature flags: Add property to `ApplicationProperties.java` + Spring config
- Secrets (dev): `application-secret-samples.yml` (template)

## Special Directories

**`src/main/resources/config/liquibase/`:**
- Purpose: Database schema migrations
- Generated: Yes (JHipster generates from JDL entities)
- Committed: Yes (version-controlled for reproducibility)
- Content: Liquibase XML/YAML changesets (create table, add column, create index, insert data)

**`src/main/resources/i18n/`:**
- Purpose: Internationalization (i18n) message bundles
- Generated: Yes (JHipster scaffolds base messages_*.properties)
- Committed: Yes
- Content: Key-value message files (e.g., messages_en.properties, messages_es.properties) for error strings, labels

**`src/main/docker/`:**
- Purpose: Docker build context and compose files
- Generated: Yes (JHipster generates Dockerfile, docker-compose.yml)
- Committed: Yes
- Content: Dockerfile (multi-stage build, JRE base image), docker-compose.yml (services: postgres, redis, kafka, zookeeper)

**`src/test/resources/`:**
- Purpose: Test configuration, fixtures, test data
- Generated: Yes (JHipster scaffolds test properties, sample test resources)
- Committed: Yes
- Content: application-test.yml (in-memory H2, test security config), mock data files

**`.jhipster/`:**
- Purpose: JHipster code generation cache and config
- Generated: Yes (created by jhipster command)
